## Описание этапа

На данном этапе реализован минимальный CLI-инструмент с конфигурацией через INI файл.

## Реализованные требования

✅ **1. Конфигурационный файл формата INI**
- Файл `stage1_config.ini` содержит все настройки
- Парсинг через стандартную библиотеку `configparser`

✅ **2. Настраиваемые параметры:**
- `package_name` — имя анализируемого пакета
- `repository_url` — URL репозитория или путь к файлу
- `test_mode` — режим работы (true/false)
- `package_version` — версия Ubuntu (focal, jammy и т.д.)
- `ascii_tree` — режим вывода ASCII-дерева (true/false)
- `max_depth` — максимальная глубина анализа (целое ≥ 0)
- `filter_substring` — подстрока для фильтрации пакетов

✅ **3. Вывод параметров в формате ключ-значение**
- Метод `Config.print_all()` выводит все параметры
- Формат: `параметр = значение`

✅ **4. Обработка ошибок:**
- Отсутствие файла конфигурации
- Отсутствие секции [settings]
- Отсутствие обязательных параметров
- Некорректные типы данных (int, bool)
- Отрицательное значение max_depth
