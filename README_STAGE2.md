## Описание этапа

На данном этапе реализована логика получения **прямых зависимостей** пакетов **без использования готовых менеджеров пакетов или библиотек**.

## Реализованные требования

✅ **1. Формат пакетов Ubuntu (apt)**
- Работа с файлом `Packages.gz` из репозитория Ubuntu
- URL формата: `{repository_url}/dists/{version}/main/binary-amd64/Packages.gz`

✅ **2. Получение данных для заданной версии пакета**
- Параметр `package_version` (focal, jammy, etc.)
- Автоматическая загрузка и распаковка Packages.gz

✅ **3. Извлечение прямых зависимостей (БЕЗ готовых инструментов)**
- Парсинг поля `Depends` вручную
- Обработка альтернативных зависимостей (`pkg1 | pkg2`)
- Удаление версионных ограничений (`>= 1.0`)

✅ **4. Вывод прямых зависимостей на экран**
- Нумерованный список всех зависимостей
- Счетчик найденных зависимостей

## Особенности реализации

### Парсинг Packages файла:

Формат файла:
```
Package: curl
Version: 7.68.0-1ubuntu2
Depends: libc6 (>= 2.17), libcurl4 (= 7.68.0-1ubuntu2), zlib1g (>= 1:1.1.4)
...

Package: wget
...
```

Алгоритм парсинга:
1. Читаем построчно
2. Пустая строка = конец описания пакета
3. Строка с `:` = новое поле
4. Строка с пробелом = продолжение предыдущего поля

### Обработка зависимостей:

Формат `Depends`: `pkg1 (>= 1.0), pkg2 | pkg3, pkg4`

1. Разделяем по запятым (`,`)
2. Берём первую альтернативу (до `|`)
3. Убираем версионные ограничения (до `(`)
4. Убираем архитектурные ограничения (до `[`)
